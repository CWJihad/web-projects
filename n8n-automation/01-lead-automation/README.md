# 🚀 Lead Automation Project

This project is a simple Lead Automation System built using **React.js** and **n8n**.

The main goal of this project is to automate lead collection and management using a frontend form and workflow automation.

---

# 📌 Project Overview

In this project:

1. A client fills out a web form
2. The submitted data is sent to the backend workflow
3. The data is automatically saved into Google Sheets
4. A confirmation email is automatically sent to the client's Gmail account

This project helped me understand:

* Frontend & automation workflow connection
* API/webhook handling
* Workflow automation using n8n
* Google Sheets integration
* Automated email sending

---
